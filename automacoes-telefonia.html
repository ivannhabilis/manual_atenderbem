Telefonia (URA telefônica)

Elementos que só existem na telefonia: áudio, DTMF e desvio de chamada. (4 elementos)

sentDTMF

Envia dígitos DTMF para a chamada — o equivalente a "teclar" no destino, usado para navegar em URAs externas ou autenticar em um provedor. O elemento é aceito pelo compilador de fluxos, mas não aparece na lista de elementos do catálogo da API desta versão: na prática ele pertence ao repertório da URA telefônica. Escreva-o sem campos, como os outros elementos sem campo obrigatório, ou complete a configuração pela interface.

Como se escreve: meu_rotulo: sentDTMF

Ao usar, valide o fluxo antes de salvar: a compilação confirma que o elemento é aceito nesta instância.

Exemplos de uso

Fluxos completos que usam os elementos deste grupo. Cada exemplo foi compilado pelo próprio sistema antes de entrar aqui.

Menu de voz com audio e leitura do teclado (URA telefonica)

Na URA telefonica, tocar um menu em audio, esperar a tecla do cliente e desviar a chamada conforme a escolha.

  1. callPlayAudio — toca o audio do menu de opcoes e pode ser interrompido pela digitacao do cliente.
  2. callWaitClientReply — para a automacao e aguarda a tecla digitada no telefone.
  3. varCondition — avalia os digitos recebidos em call_digits e cria um ramo por opcao.
  4. callTransfer — desvia a chamada para o numero correspondente a tecla pressionada.
  5. callTerminate — derruba a chamada com hangup quando a opcao nao existe.
toca_menu: callPlayAudio fileChooseType=1 fileId="{{audio_menu_principal}}" stopOnUserInput=true
espera_tecla: callWaitClientReply
le_tecla: varCondition value="{{call_digits}}" {
  case vendas conditionOperator="=" conditionValue="1" {
    desvia_vendas: callTransfer destinationNumber="2001"
  }
  case suporte conditionOperator="=" conditionValue="2" {
    desvia_suporte: callTransfer destinationNumber="2002"
  }
  else {
    opcao_invalida: callPlayAudio fileChooseType=1 fileId="{{audio_opcao_invalida}}"
    derruba: callTerminate reason="Opcao invalida"
  }
}
Resultado: Digitando 1 ou 2 o cliente e desviado para o ramal certo; qualquer outra tecla toca um aviso e a chamada e encerrada com hangup.

Desviar conforme a tecla e enviar DTMF ao PABX de destino (URA telefonica)

Na URA telefonica, ler a tecla, repassar um DTMF para o PABX de destino e so depois completar a chamada.

  1. callPlayAudio — toca o audio do menu e (por nao ser interrompivel) deixa a mensagem terminar.
  2. callWaitClientReply — aguarda a tecla digitada pelo cliente.
  3. sentDTMF — envia o DTMF configurado no elemento, guiando o menu do PABX de destino antes de completar a chamada.
  4. callTransfer — desvia a chamada para o destino conforme a tecla.
  5. callTerminate — encerra a chamada com hangup no ramo de opcao invalida.
toca_menu: callPlayAudio fileChooseType=1 fileId="{{audio_menu_principal}}" stopOnUserInput=false
espera: callWaitClientReply
decide: varCondition value="{{call_digits}}" {
  case comercial conditionOperator="=" conditionValue="1" {
    desvia_comercial: callTransfer destinationNumber="2100"
  }
  case financeiro conditionOperator="=" conditionValue="2" {
    envia_dtmf: sentDTMF
    desvia_financeiro: callTransfer destinationNumber="2200"
  }
  else {
    despedida: callPlayAudio fileChooseType=1 fileId="{{audio_despedida}}"
    derruba: callTerminate reason="Opcao invalida"
  }
}
Resultado: A tecla 1 desvia direto para o comercial; a tecla 2 envia o DTMF e desvia para o financeiro; sem escolha valida a chamada e derrubada.

Encerrar a chamada com hangup (URA telefonica)

Na URA telefonica, tocar um aviso e encerrar a ligacao com hangup.

  1. callPlayAudio — toca o audio de fora do horario na chamada.
  2. callTerminate — encerra a chamada com hangup e registra o motivo.
avisa_fechado: callPlayAudio fileChooseType=1 fileId="{{audio_fora_horario}}" stopOnUserInput=true
encerra_chamada: callTerminate reason="Fora do horario de atendimento"
Resultado: O cliente ouve o aviso e a ligacao e encerrada imediatamente com hangup.
