Gestão de Ramais (Extensions) e Softphones

Como criar e administrar ramais PJSIP, configurar telefones físicos/MicroSIP, habilitar gravação de chamadas e vincular o Webphone ao sistema AtenderBem.

1. O que é um Ramal (Extension)?

O Ramal é o ponto de terminação individual de cada atendente ou estação de trabalho. Ele permite que os colaboradores conversem gratuitamente entre si dentro da empresa e recebam ou realizem chamadas externas através dos troncos SIP.

Tipo de RamalOnde é UtilizadoProtocolo / Recomendação
Ramal Webphone (Navegador)Diretamente dentro do painel do AtenderBem, sem instalar nada.PJSIP / WebRTC (Recomendado para agentes de atendimento).
Ramal Softphone (Computador)Aplicativos de desktop como MicroSIP, Zoiper ou Linphone.PJSIP / SIP UDP/TCP (Recomendado para estações administrativas).
Telefone IP Físico / ATAAparelhos de mesa físicos (Yealink, Grandstream, Intelbras).PJSIP / SIP UDP com registro no IP público do PABX.

2. Passo a Passo: Criando um Ramal PJSIP no FreePBX

  1. No menu do PABX, acesse Applications › Extensions › Add Extension › Add New PJSIP Extension.
  2. Aba General:
    • User Extension: Número numérico do ramal (ex.: 1001, 1002, 2001).
    • Display Name: Nome do atendente ou departamento (ex.: Carlos Silva - Suporte).
    • Outbound CID: Identificador enviado ao discar externamente (opcional, pode herdar do tronco).
    • Secret: Senha alfanumérica forte gerada pelo sistema. Copie este valor!
  3. Aba Recording Options (Gravação de Voz):
    • Inbound External Calls: Definir como Force ou Yes para gravar todas as ligações recebidas de clientes.
    • Outbound External Calls: Definir como Force ou Yes para gravar todas as ligações feitas pelos atendentes.
  4. Aba Voicemail (Caixa Postal - Opcional):
    • Habilite Status = Enable, defina uma senha numérica e insira o e-mail do atendente para receber o áudio da mensagem por e-mail em formato WAV.
  5. Clique em Submit e depois em Apply Config no topo da tela.

3. Vinculando o Ramal ao Atendente no AtenderBem

Após criar o ramal no PABX, é necessário vinculá-lo ao cadastro do operador no sistema omnichannel:

  1. No sistema AtenderBem, acesse Configurações › Usuários.
  2. Localize o atendente na listagem e clique no ícone de edição.
  3. Nas opções do formulário, ative a chave "Habilitar softphone".
  4. No campo Ramal, informe o número da extension criada (ex.: 1001).
  5. No campo Senha, cole o secret copiado do PABX.
  6. Clique em Salvar.
Verificação em Tempo Real: Quando o atendente fizer login no AtenderBem, o ícone do telefone no cabeçalho ficará Verde indicando registro SIP com sucesso. No PABX, execute asterisk -rx "pjsip show endpoints" para ver o ramal em estado Available / Reachable.

4. Configuração em Aplicativos Softphone (Ex: MicroSIP)

Caso o atendente utilize um aplicativo desktop (MicroSIP):

  • Account Name: Nome do atendente (ex.: Carlos).
  • SIP Server: IP Externo do PABX (obtido no Asterisk SIP Settings) ou domínio (ex.: pabx.suaempresa.com.br).
  • User / Login: Número do ramal (ex.: 1001).
  • Password: O secret do ramal.
  • Media Encryption: Desativado para conexões locais padrão ou Mandatory SRTP se configurado com TLS.

5. Tipo do Ramal no PABX Fácil: Softphone vs Webphone

Além do cadastro do protocolo (PJSIP), o PABX Fácil permite classificar o ramal pelo seu tipo de uso, determinando em qual interface ele será consumido:

Tipo do RamalPara que Serve
Tipo SoftphoneUsado por softwares de desktop (MicroSIP e similares) e por telefones IP físicos.
Tipo WebphoneUsado dentro do sistema de atendimento (navegador), sem instalação de software no posto de trabalho.
A definição do tipo é feita no PABX. O vínculo do ramal com o atendente continua sendo feito em Configurações › Usuários, conforme a seção 3.

6. Aba Advanced do Ramal PJSIP (WebRTC e Mídia)

Para que o ramal opere como webphone no navegador, é preciso habilitar os parâmetros de conectividade de mídia na aba Advanced do formulário Add PJSIP Extension. Conforme o guia do parceiro, estes campos devem estar definidos como Yes:

Parâmetro (aba Advanced)Valor RecomendadoFinalidade
Enable AVPFYesHabilita o perfil de feedback de áudio/vídeo (RTCP) usado pelo WebRTC.
Enable ICE SupportYesPermite a descoberta de caminho de mídia (ICE/STUN) para conexões atrás de NAT.
Enable WebRTCYesHabilita o endpoint para chamadas WebRTC (webphone no navegador).
  1. Acesse Applications › Extensions e clique no ícone de editar o ramal desejado.
  2. Abra a aba Advanced (role a página, os parâmetros ficam mais abaixo).
  3. Ajuste Enable AVPF, Enable ICE Support e Enable WebRTC para Yes.
  4. Clique em Submit e depois em Apply Config.

7. Atualizar o NAT e Obter o IP Externo do PABX

O IP externo é o endereço usado para configurar telefones IP e aplicativos VoIP (tipo MicroSIP) que se conectam de fora da rede local. Sem o IP externo correto no NAT, ramais externos não conseguem registrar.

  1. No PABX, acesse Settings › Asterisk SIP Settings.
  2. Abra a aba General SIP Settings.
  3. Em NAT Settings, no campo External Address, clique no botão Detect Network Settings.
  4. O IP será atualizado automaticamente — utilize-o para configurar os acessos externos (softphones e telefones IP).
O mesmo IP externo detectado aqui é o valor a informar no campo SIP Server dos aplicativos softphone (veja a seção 4).

8. Diagnóstico de Ramais via CLI

Comandos Asterisk úteis para conferir o cadastro e o registro dos ramais:

# Lista todos os ramais (endpoints PJSIP) cadastrados:
asterisk -rx "pjsip show endpoints"

# Exibe a configuração detalhada do ramal 2000:
asterisk -rx "pjsip show endpoint 2000"

# Ramais registrados no momento:
asterisk -rx "pjsip show contacts"
asterisk -rx "pjsip show registrations"

# Transportes configurados (UDP / TCP / TLS):
asterisk -rx "pjsip show transports"

# Testa se o ramal responde (envia OPTIONS ao endpoint):
asterisk -rx "pjsip qualify endpoint 2000"
Para depurar o registro SIP em detalhe, ative asterisk -rx "pjsip set logger on" (e desative depois com pjsip set logger off) para visualizar os pacotes SIP no console.
