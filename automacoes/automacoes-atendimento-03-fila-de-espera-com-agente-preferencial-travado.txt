aviso: message text="Vou verificar se ha um agente livre para te atender agora."
espera: addToWaitingList
checa: userAvailable variableName="agente" userId="4"
decide: varCondition value="{{agente}}" {
  case livre conditionOperator="not null" {
    sai_espera: removeFromWaitingList
    trava: lock userId="4" lockTime=300
    avisa_cliente: message text="Pronto! {{agente.agent_full_name}} vai assumir seu atendimento. Aguarde um instante."
    entrega: transfer destinationType=1 destinationId="4" -> end
  }
  else {
    mantem: message text="Todos os agentes estao ocupados. Voce ficou na fila de espera e sera chamado assim que alguem liberar."
    fim: terminate reason="Cliente na fila de espera" obs="Nenhum agente disponivel agora: atendimento mantido na fila de espera."
  }
}
