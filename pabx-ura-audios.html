Gravações de Áudio, Anúncios e Menus de URA (IVR)

Como fazer upload de áudios profissionais, criar mensagens informativas (Announcements) e estruturar menus vocais interativos de autoatendimento.

1. Gravações do Sistema (System Recordings)

As Gravações do Sistema são a base sonora da central. Elas contêm as vozes que os clientes escutam ao ligar para a empresa.

Padrão Técnico de Áudio para Telefonia: Para máxima clareza e compatibilidade com o Asterisk, os arquivos de áudio devem estar no formato WAV PCM, 16-bit Mono, taxa de amostragem de 8000 Hz ou 16000 Hz. Arquivos em MP3 ou estéreo sofrem conversão e podem gerar ruído.

Como cadastrar um áudio no FreePBX:

  1. No menu do PABX, acesse Admin › System Recordings › + Add Recording.
  2. Clique em Upload Recording e selecione o arquivo .wav gravado em seu computador.
  3. Defina um Name descritivo (ex.: Audio_Menu_Principal ou Audio_Fora_Horario).
  4. Clique em Save e aplique as alterações com Apply Config.

2. Anúncios Informativos (Announcements)

Um Anúncio (Announcement) reproduz uma mensagem gravada para o cliente e, imediatamente após o fim da fala, transfere a chamada para o próximo destino automaticamente, sem esperar interação de teclas.

Casos de uso comuns:

  • "Esta ligação está sendo gravada para fins de controle de qualidade..." ➔ Direciona para a Fila de Atendimento.
  • "Nosso horário de atendimento é de segunda a sexta, das 8h às 18h..." ➔ Direciona para Desligar (Hangup) ou Caixa Postal.
  • "Estamos realizando manutenção técnica preventiva..." ➔ Direciona para a URA de Emergência.

Para configurar, acesse Applications › Announcements › + Add Announcement, selecione a gravação cadastrada no campo Recording e defina o destino final em Destination after playback.

3. Criação de URA / IVR (Interactive Voice Response)

A URA (IVR) é o menu eletrônico que orienta o cliente: "Olá, bem-vindo à Central de Atendimento! Digite 1 para Suporte Técnico, 2 para Financeiro, ou 3 para Vendas."

Passo a passo no FreePBX (`Applications › IVR`):

  1. Acesse Applications › IVR › + Add IVR.
  2. Defina o IVR Name (ex.: URA_Principal_Diurna).
  3. No campo Announcement, selecione a gravação com as opções de menu (ex.: Audio_Menu_Principal).
  4. Timeout: Defina o tempo de espera pelo dígito do cliente (padrão: 5 segundos).
  5. Invalid Retries: Número de tentativas permitidas se o cliente digitar uma opção inexistente (ex.: 2).
  6. Timeout Destination: O que fazer se o cliente não digitar nada (ex.: repetir o menu ou transferir para a recepção).
  7. Tabela de Entradas (IVR Entries): Mapeie os dígitos numéricos para seus destinos:
    Dígito DTMFDestino (Destination)Descrição
    1Queues › Fila_SuporteDireciona para os técnicos de suporte.
    2Queues › Fila_FinanceiroDireciona para faturamento/cobrança.
    3Queues › Fila_ComercialDireciona para o time de vendas.
    9Extensions › 1000 (Recepção)Atendimento humano geral.
    t (Timeout)IVR › URA_Principal_DiurnaRepete o menu caso nada seja digitado.
    i (Invalid)Announcements › Opcao_InvalidaToca aviso de opção incorreta.
  8. Clique em Submit e em Apply Config.
