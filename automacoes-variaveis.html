O que é uma variável. Praticamente todo campo de um fluxo aceita {{expressão}}. O caso mais simples é {{nome_da_variavel}}, que devolve o valor daquela variável no momento da execução. Este capítulo reúne as variáveis que o sistema oferece e as expressões que se pode montar com elas.

1. Sintaxe das expressões

RegraExemplo
Tudo entre chaves duplas é uma expressão avaliada.{{chat_client_name}}
Texto entre aspas, concatenado com +.{{"Olá, " + contact_name + "!"}}
Acesso a propriedade de objeto e a item de lista.{{chat_contact.contact_name}} · {{chat_opportunities_list[0].opportunity_title}}
Não é permitido chamar método nem função — a chamada devolve vazio. Para converter texto em número use x * 1.{{pedido_valor * 1 + 10}}
Variável global vale em todos os fluxos da mesma fila e usa o prefixo global..{{global.contador}}
As variáveis vivem em memória. Elas se perdem se o serviço for reiniciado — para guardar algo que precisa durar, use o banco de valores persistentes.

TipoOperadoresExemplo

3. Filtros (pipes)

Sintaxe {{valor | filtro:param1:param2}}, encadeáveis da esquerda para a direita.

FiltroO que faz
toUpperCase / toLowerCaseCaixa alta / caixa baixa.
capitalizePrimeira letra de cada palavra em maiúscula.
truncate:tamanho[:sufixo]Limita o texto (sufixo padrão "...").
default:"alternativa"Devolve a alternativa quando o valor é vazio, nulo ou indefinido.
phone:"BR"|"US"Formata telefone (o BR aceita com ou sem DDI 55).
split:"separador"[:indice]Quebra o texto; sem índice devolve a lista, com índice devolve só aquele trecho (base 0; negativo conta do fim).
substring:inicio[:tamanho]Extrai um trecho do texto.
toFixed:casasFixa as casas decimais.
currency:"MOEDA":casasFormata como moeda (BRL, USD, EUR, GBP e outras).
formatDate:"DD/MM/YYYY"Formata data (padrões do moment).
addToDate:qtd:"unidade" / subtractToDateSoma/subtrai tempo (seconds, minutes, hours, days, weeks, months, years).

4. Expressão avaliada como valor

Vale para o ramo expression da condição e para a lista/contagem do laço. Aqui a expressão é pura, sem chaves, com as variáveis pelo nome.

  • conditionValue="pedido_valor * 1 > 100 && cidade == "SP"" — o ramo vale quando o resultado é verdadeiro.
  • list="{{chat_opportunities_list}}" e count="{{quantidade}}" no laço.
  • O resultado não vira texto: a lista chega como lista e a condição vale no sentido do JavaScript — false, 0, "", null e variável inexistente são falsos; qualquer texto não vazio é verdadeiro, inclusive "0". Para checar número, compare x * 1 > 0.
  • Variável inexistente não é igual a "": para "vazia ou inexistente" use !x.
  • Não é permitido: atribuição, mais de um comando, chaves dentro da expressão, função ou método.

5. Variáveis do sistema são somente leitura

As variáveis que o sistema fornece — as que descrevem o atendimento, a mensagem, a fila e o momento — refletem o estado atual e não podem ser gravadas pelo fluxo. Gravar num nome de sistema (com newVar, no retorno do jscode, no varName de uma pergunta ou no itemVar de um laço) não tem efeito: o valor continua o do sistema, e a gravação ignorada aparece como alerta na depuração do elemento.

Exceção — dados do cliente do atendimento, graváveis apenas pelo elemento newVar ou pelo retorno do jscode, que os gravam no próprio atendimento: chat_client_name, chat_client_number, chat_client_email, chat_client_profile_name, chat_client_data e clientDocument.

Para os seus próprios dados, use nomes próprios (ex.: pedido_total, cliente_cpf) — esses são variáveis do fluxo, livres para gravar e regravar.

6. Armadilhas

  • Expressão que falha vira texto vazio, silenciosamente. Vazio no resultado é sinal de expressão errada, não de valor ausente.
  • toFixed e currency só operam sobre número. Aplicados a texto derrubam a expressão inteira; e com o valor 0 devolvem 0 sem formatar.
  • O filtro tem precedência menor que o ternário: {{x ? "a" : "b" | toUpperCase}} aplica o filtro só ao "b". Use parênteses.
  • Vírgula decimal não é número: converta antes de somar ou comparar.
